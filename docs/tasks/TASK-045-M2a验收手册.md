## 目标

把 M2a 变成一个**用户照做就能跑起来**的东西。用户不懂技术：手册必须是"复制-粘贴-看到结果"的形态，

## 交付内容

### A. `docs/plan/m2a-acceptance.md`

按顺序覆盖：

1. **一句话是什么**：本地起服务 + 编辑器接 MCP → 编辑器里的 AI 能问到你的仓库（含行号证据）。
2. **前置**：WSL 里有哪些命令可用（`uv`），第一次要花多久（模型下载/首次索引，如实说时间量级）。
3. **起服务**（一条命令）：`zace-service local --repo <仓库路径> --port 8787`，贴真实输出，
   写清"看到 `xxx` 就是在索引中，可以先去配编辑器"。
4. **配编辑器**：Cursor 的 `mcp.json`（项目内 `.cursor/mcp.json` vs 全局 `~/.cursor/mcp.json`），
   贴出 TASK-040 输出的 JSON 片段；说明"什么时候需要重启编辑器"。
5. **验证**（3 步，各给期望结果）：
   - `/healthz`（curl，贴期望 JSON 形状）
   - 在编辑器里问一个**已知答案**的问题（用 zace 自己的仓库，例如"BM25 查询侧噪声过滤在哪个文件实现？"），
     贴出 AI 调用 `search_context` 后拿到的证据行；写明"成功 = 出现 `路径:行号` 且路径真实存在"
   - 故意问一个仓库里不存在的东西，验证**诚实性**：应当看到 `answerable=false` / 缺少证据的说明，
     **而不是编造**（这是 D-24 的验收点，也是本项目相对 grep 的核心差异）
6. **排错表**（每行：现象 → 原因 → 处理）：
   - 编辑器里看不到 zace 工具 → 服务没起 / URL 写错 / 需要重启编辑器
   - 工具返回"尚未索引" → 看 `/healthz` 的进度；等服务索引完
   - 返回 `embedding_unavailable` → 模型没下载好或配置错（写明检查项）
   - 检索结果里出现 `cmake-build-*/`、`.claude/skills/**` 之类噪声 → 说明当前忽略规则的状态（TASK-037）
7. **已知限制**（诚实清单）：`ask_project` 是降级包（LLM 属 Phase 3）；多仓聚合不支持；
   无鉴权（仅本机 127.0.0.1）；索引期间检索会返回"进行中"。

### B. `scripts/demo-rehearsal.sh`（幂等、可重复）

不做人工步骤，全部自动：

```text
1. 起服务（后台，用临时 data_root 以免污染用户数据）
2. 轮询 /healthz 直到目标 project 索引完成（带超时与进度打印）
3. 用最小 MCP 客户端走 initialize → tools/list → tools/call（复用 TASK-040 的测试客户端形态）
4. 跑 3 条查询：一条已知答案、一条不存在（诚实性）、一条 ask_project（降级）
5. 打印每步 PASS/FAIL 与耗时，最后给总结行
```

- 脚本必须**不用**任何手工参数就能在小仓库上跑通（默认在 `zace` 仓库自身上跑）；
- 失败要打印可操作信息（不是裸 traceback）；
- 结束清理后台进程（trap）。
